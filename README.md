## 🧠 AI Project Explainer

An AI-powered developer tool designed to help developers quickly understand unfamiliar software projects.

Users can upload a **ZIP file containing a complete codebase**, and the application analyzes the project structure and generates an AI-powered explanation of its architecture and components.

### ✨ Highlights

* 📦 ZIP project upload
* 📂 Automatic project structure analysis
* 🔍 Source-code exploration
* 🏗️ Architecture explanation
* 🧩 Component relationship analysis
* 🤖 AI-generated project documentation
* 📚 Useful for developers learning unfamiliar codebases

### 🧰 Technology

**Backend:** Python · Flask
**AI:** Claude API
**Input:** ZIP / Source Code

### 💡 Why I Built It

Large codebases can be difficult to understand when joining an existing project or learning a new technology.

This project uses AI to make codebase exploration faster by generating an understandable overview of the project's **structure, architecture, components, and functionality**.
